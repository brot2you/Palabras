# ¡PALABRAS! — Barrio Pop V2

Version de l’application V1 avec nouvelle direction artistique Barrio Pop.

## Installation
Publier `index.html` et le dossier `assets/` à la racine du dépôt GitHub Pages.

## Fonctionnement
Les menus, boutons et activités sont de vrais éléments HTML interactifs ; la grande illustration est décorative. Les données lexicales, jeux, BD et sauvegardes V1 sont conservés.

## Contenu
- `assets/barrio-pop-cover.webp` : illustration d'accueil
- `assets/equipo-barrio.webp` : bande décorative de personnages
- `assets/concept.png` : ancienne planche conservée comme archive

La création de six portraits transparents séparés et d'illustrations lexicales individuelles reste une étape ultérieure.
