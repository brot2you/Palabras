# ¡PALABRAS! V1 — by BROT2YOU

Application statique d'initiation et de consolidation du vocabulaire espagnol pour le collège.

## Installation
Ouvrir `index.html` dans un navigateur, ou publier `index.html` et le dossier `assets/` à la racine d'un dépôt GitHub Pages.

## Fonctionnalités
- 13 thèmes et 104 entrées lexicales initiales, 5e à 3e, avec accès aux acquis des niveaux précédents.
- Fiches lexicales, recherche, synthèse vocale espagnole du navigateur.
- Quiz espagnol/français, français/espagnol et reconnaissance audio.
- Progression locale et import/export JSON.
- Premier épisode de BD interactif sous forme de prototype.

## Limites connues
- Les illustrations des fiches sont des pictogrammes emoji provisoires.
- Les voix dépendent du navigateur et de l'appareil.
- Le moteur de révision temporelle et les 8 ateliers complets sont prévus pour une version suivante.
- Le visuel `assets/concept.png` est une planche d'intention graphique, pas un écran final.
